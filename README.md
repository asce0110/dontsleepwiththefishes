# Don't Sleep With The Fishes — Wiki

Fan-made survival guide and wiki for [Don't Sleep With The Fishes](https://dopplerghost.itch.io/dont-sleep-with-the-fishes) by DopplerGhost.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- React Router v7
- Motion (Framer Motion)
- Lucide React

## Setup

```bash
pnpm install
pnpm run dev
```
